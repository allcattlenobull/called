# Localization foundation

Called currently ships in English. The interface now includes a lower-density plain reading mode, but this is not a translation.

Before adding Spanish or another language:

1. move interface copy into locale dictionaries while keeping research citations and version labels stable;
2. use professional translation plus community review for career, faith, privacy, and assessment language;
3. validate translated instruments as translated instruments—do not assume English reliability or norms transfer;
4. test text expansion, reading order, screen readers, date/currency formats, and search synonyms;
5. show content-language and last-reviewed metadata, with a clear English fallback;
6. recruit target-language users for comprehension and trust testing before release.

Machine translation may support drafts, but it should not silently generate assessment items or evidence claims.
